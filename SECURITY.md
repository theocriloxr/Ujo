# Security reports

Use the repository's private security advisory reporting facility if enabled.
If it is unavailable, contact the repository owner privately to establish a secure
reporting channel. Do not post credentials, customer data or exploit details in
public issues. This document does not promise a response time or certification.

Keep tokens outside source control, provide only the authority needed, and revoke
them through the issuing system when compromised. Public CI requires no secrets,
private repositories or production endpoints.
